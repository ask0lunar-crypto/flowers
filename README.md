# Flowers — лабораторная работа №3

Локальное веб-приложение магазина цветов по макету этапа 2. Структура рабочей базы данных реализована в MariaDB через phpMyAdmin. SQL для импорта находится в `schema_mysql.sql`.

## Запуск

```powershell
python app.py
```

Открыть `http://127.0.0.1:8765/`.

Демо-администратор: `admin@flowers.local`, пароль `admin123`.

В `schema_mysql.sql` находятся пять таблиц и пять представлений: сводка заказов, популярные товары, статистика клиентов, рейтинг товаров и продажи по дням. База `flowers` создана в XAMPP MariaDB и доступна через `http://127.0.0.1/phpmyadmin/`. Панель администратора сайта доступна после входа под демо-администратором.

Каталог доступен через JSON API `GET /api/products`, который возвращает активные товары из локальной БД. Фотографии карточек заменены на локальные кадры тех же букетов, которые используются в макете Figma. В интерфейсе подключены адаптивная вёрстка, формы регистрации/авторизации с браузерной валидацией, личный кабинет, корзина и конструктор букета.
